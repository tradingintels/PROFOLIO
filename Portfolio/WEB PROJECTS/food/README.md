# Moobiq Food - Premium Agricultural Website

## Project Overview

## Website Structure

### Pages
- **index.html** - Main homepage with hero video, business ecosystem, statistics, and featured products
- **about.html** - Company story, mission, vision, core values, leadership, and timeline
- **product.html** - Product catalog with categories, featured products, and FAQs
- **services.html** - Comprehensive agribusiness services
- **agribusiness.html** - Agribusiness programs and farmer support
- **gallery.html** - Photo gallery with filtering capabilities
- **news.html** - Latest news and updates
- **contact.html** - Contact form, information, and map

## Features

### Design & UX
- **Windows 8 Metro UI** - Modern tile-based design system
- **Video Background** - Immersive hero section
- **Loading Animation** - Professional preloader with progress bar
- **Scroll Reveal** - Smooth section animations on scroll
- **3D Product Cards** - Interactive perspective effects
- **Floating Action Buttons** - WhatsApp, Call, and Back-to-Top
- **Dark Mode Support** - Toggle between light and dark themes
- **Mobile Responsive** - Fully responsive on all devices

### Technical Features
- **Pure CSS/JavaScript** - No external dependencies
- **Font Awesome 6.6** - Premium icon library
- **Poppins Font** - Modern typography
- **CSS Grid & Flexbox** - Modern layout techniques
- **CSS Variables** - Consistent design system
- **Smooth Scrolling** - Enhanced navigation experience
- **Form Validation** - Contact and newsletter forms
- **FAQ Accordion** - Interactive FAQ section

### SEO Optimized
- Meta descriptions and keywords on all pages
- Semantic HTML5 structure
- Proper heading hierarchy
- Alt attributes for images
- Clean URLs

## Setup Instructions
1. Clone/download the project
2. Add your images to the respective folders
3. Add a hero video to `videos/hero.mp4`
4. Open `index.html` in a web browser

## Customization
- Update content in HTML files
- Modify colors in `css/style.css` under `:root`
- Add new sections following existing patterns
- Update contact information in footer

## Performance
- Optimized CSS with minimal redundancy
- Efficient JavaScript with event delegation
- Lazy loading for images
- Minified assets for production
